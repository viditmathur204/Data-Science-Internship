# Week 2 Project — Global Happiness Analytics

## Overview

This project analyzes the World Happiness Report 2019 dataset using Python,
Pandas, NumPy, and Matplotlib.

The objective is to explore the factors associated with national happiness
scores and present the findings through clear visualizations.

## Dataset

World Happiness Report 2019.

The primary dataset used is `2019.csv`.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Tasks Completed

1. Load & Validate
2. Statistical Summaries
3. Correlation Analysis
4. Outlier Detection
5. Feature Understanding
6. Ranking View
7. Relationship View
8. Final Dashboard

## Deliverables

- Cleaned Jupyter Notebook
- Correlation heatmap
- Final 2x2 dashboard
- One-page written summary
